# Pickled field guide

[Read the guide](https://chuckpearson.github.io/pickled-guide/) for the Pickled Apple Watch and iPhone TestFlight beta.

This repository contains only tester documentation and screenshots made with sample data. App source and tester records are not included.

For feedback, use TestFlight → Pickled → Send Beta Feedback, or Pickled → Settings → Send Feedback. You can also email chuck@rareview.com.

GitHub Pages serves the `main` branch at the repository root. The site is plain HTML/CSS, with no analytics or external scripts.
